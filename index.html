Unidad 1: Introducción al Desarrollo Web Orientado a Servicios

Esta sección fue desarrollada colaborativamente por Edgar Reyes (diseño de contenido) y Ramiro Alejandro (contenido técnico).

1. Paradigma del desarrollo de aplicaciones orientadas a servicios

Servicios en la nube

Distinguir los servicios que se ofrecen en la nube: SaaS (Software como Servicio), PaaS (Plataforma como Servicio), IaaS (Infraestructura como Servicio).

Características de las aplicaciones orientadas a servicios
  • Modularidad y reutilización de componentes
  • Interoperabilidad entre diferentes sistemas
  • Escalabilidad y flexibilidad
  • Bajo acoplamiento entre servicios
  • Abstracción de la implementación subyacente
Aplicaciones web híbridas (Mashup)

Identificar el concepto y las características de las aplicaciones web híbridas que combinan datos o funcionalidades de múltiples fuentes para crear un nuevo servicio integrado.

2. Arquitectura Orientada a Servicios (SOA)

Definición de SOA

La Arquitectura Orientada a Servicios (SOA) es un estilo de arquitectura de software que permite la creación de sistemas a partir de servicios reutilizables e interoperables, los cuales se comunican a través de estándares bien definidos.

Principios de diseño
  • Contratos de servicio estandarizados
  • Bajo acoplamiento entre servicios
  • Abstracción de la lógica de negocio
  • Reutilización de servicios
  • Autonomía de los servicios
  • Descubrimiento de servicios
  • Composición de servicios
Estándares relacionados
XML (eXtensible Markup Language)

Lenguaje de marcado extensible para estructuración de datos.

SOAP (Simple Object Access Protocol)

Protocolo para intercambio de información en servicios web.

WSDL (Web Services Description Language)

Lenguaje para describir interfaces de servicios web.

UDDI (Universal Description, Discovery and Integration)

Registro de servicios web para su descubrimiento.

REST (Representational State Transfer)

Estilo arquitectónico para sistemas distribuidos, basado en HTTP y principios de recursos y operaciones estándar.

🌍 Geolocalización
¿Qué es la Geolocalización?

La geolocalización es una tecnología que permite conocer la ubicación de una persona, dispositivo u objeto en tiempo real mediante el uso de GPS, redes móviles o conexión a internet.

Aplicaciones Prácticas:
  • Google Maps: Navegación y búsqueda de lugares
  • Uber/Didi: Servicios de transporte y entrega
  • Apps de entrega: Seguimiento de pedidos en tiempo real
  • Redes sociales: Etiquetado de ubicaciones y lugares cercanos
  • Aplicaciones meteorológicas: Pronóstico del tiempo por ubicación
Ventajas principales:
  • Facilita la navegación y orientación
  • Mejora servicios personalizados
  • Optimiza la toma de decisiones basadas en ubicación
  • Permite servicios de emergencia más eficientes
  • Fomenta el comercio local y promociones geográficas
Implementación en APIs: Las APIs de geolocalización como Google Maps API, Mapbox o OpenStreetMap permiten integrar mapas, calcular rutas y obtener coordenadas en aplicaciones web.
📱 Redes Sociales
¿Qué son las Redes Sociales?

Las redes sociales son plataformas digitales que permiten la comunicación, interacción y el intercambio de información entre personas o grupos.

Principales plataformas:
  • Facebook: Red social generalista más popular
  • Instagram: Red visual centrada en fotos y videos
  • TikTok: Plataforma de videos cortos virales
  • X (Twitter): Red de microblogging y noticias
  • WhatsApp: Aplicación de mensajería instantánea
  • LinkedIn: Red profesional y de negocios
Usos principales:
  • Compartir contenido: Fotos, videos, textos y enlaces
  • Comunicación: Mensajes directos y grupos de chat
  • Promoción de negocios: Marketing digital y publicidad
  • Creación de comunidades: Grupos de interés común
  • Entretenimiento: Contenido viral y tendencias
Integración con APIs: Las APIs de redes sociales (Facebook Graph API, Twitter API, Instagram Basic Display API) permiten autenticación con redes sociales, publicación programática y obtención de datos de usuarios.
🗄️ Bases de Datos
¿Qué son las Bases de Datos?

Las bases de datos son sistemas que permiten almacenar, organizar y gestionar grandes cantidades de información de forma estructurada y eficiente.

Tipos de Bases de Datos:
SQL (Relacionales):
  • MySQL
  • SQL Server
  • Oracle Database
  • PostgreSQL
NoSQL (No relacionales):
  • MongoDB
  • Firebase
  • Cassandra
  • Redis
Aplicaciones comunes:
  • Aplicaciones web: Almacenamiento de usuarios, productos y transacciones
  • Sistemas administrativos: Registro de empleados, inventarios y ventas
  • Plataformas educativas: Gestión de estudiantes, cursos y calificaciones
  • Comercio electrónico: Catálogos de productos y órdenes de compra
  • Aplicaciones móviles: Datos locales y sincronización en la nube
Microsoft Access:

Es un sistema de gestión de bases de datos relacional desarrollado por Microsoft, ideal para pequeñas y medianas aplicaciones de escritorio.

Conectividad con APIs: Las APIs RESTful permiten interactuar con bases de datos a través de operaciones CRUD (Crear, Leer, Actualizar, Eliminar) usando estándares HTTP.

🎬 Plataformas Streaming
¿Qué son las Plataformas de Streaming?

Las plataformas de streaming permiten la transmisión de contenido multimedia (videos, series, películas o música) en tiempo real a través de internet, sin necesidad de descargar los archivos completos.

Principales plataformas:
Video
  • Netflix
  • YouTube
  • Disney+
  • Amazon Prime Video
Música
  • Spotify
  • Apple Music
  • Deezer
  • Tidal
Videojuegos
  • Twitch
  • YouTube Gaming
  • NVIDIA GeForce Now
  • Xbox Cloud Gaming
Características destacadas:
  • Accesibilidad: Disponibles desde múltiples dispositivos (smartphones, tablets, smart TVs, computadoras)
  • Variedad de contenido: Catálogos extensos y actualizados regularmente
  • Personalización: Recomendaciones basadas en preferencias de usuario
  • Calidad adaptable: Ajuste automático de calidad según conexión
  • Multiusuario: Perfiles individuales y acceso simultáneo
Ventajas del streaming:
  • Sin necesidad de almacenamiento local
  • Acceso inmediato al contenido
  • Actualizaciones automáticas
  • Contenido disponible 24/7
  • Mayor seguridad contra piratería
  • Suscripciones flexibles
APIs de streaming: Plataformas como YouTube Data API, Spotify Web API y Twitch API permiten a desarrolladores integrar funcionalidades de streaming, buscar contenido y controlar la reproducción en sus aplicaciones.
¿Qué es una API?

Una Interfaz de Programación de Aplicaciones (API) es un conjunto de definiciones y protocolos que permite la comunicación e integración entre diferentes aplicaciones de software.

Características principales:
  • Interfaz definida: Especifica cómo interactuar con el servicio
  • Protocolos estandarizados: Usa HTTP, REST, SOAP, GraphQL, etc.
  • Abstracción: Oculta la complejidad interna del servicio
  • Reutilización: Permite usar funcionalidades existentes
  • Escalabilidad: Facilita el crecimiento del sistema
¿Cómo funcionan las APIs en los temas vistos?
🌍 Geolocalización

APIs como Google Maps permiten integrar mapas, calcular rutas y obtener ubicaciones en tiempo real.

📱 Redes Sociales

APIs de Facebook, Twitter, etc., permiten autenticación, publicación y obtención de datos de usuarios.

🗄️ Bases de Datos

APIs RESTful permiten operaciones CRUD (Crear, Leer, Actualizar, Eliminar) sobre datos.

🌐 Plataformas

APIs de plataformas permiten integraciones con servicios de terceros y extensiones.

🎬 Streaming

APIs de YouTube, Spotify, etc., permiten buscar contenido, controlar reproducción y obtener estadísticas.

Tipos de API
  • REST Arquitectura basada en HTTP
  • SOAP Protocolo XML basado en mensajes
  • GraphQL Lenguaje de consulta para APIs
  • WebSocket Comunicación bidireccional en tiempo real

Frameworks en el Desarrollo de Aplicaciones Orientadas a Servicios
🔎 ¿Qué es una aplicación orientada a servicios?

Una aplicación orientada a servicios (SOA – Service Oriented Architecture) es un modelo de desarrollo donde el sistema se divide en servicios independientes que se comunican entre sí mediante protocolos como HTTP. Actualmente este modelo también se implementa con microservicios, donde cada servicio cumple una función específica y puede desarrollarse de manera independiente.

🧩 Frameworks más utilizados
  • 1️⃣ Express.js: Framework de Node.js, ligero y flexible, muy utilizado para crear APIs REST, permite manejar rutas, middleware y peticiones HTTP, ideal para aplicaciones backend rápidas y escalables.
  • 2️⃣ Django: Framework de Python que incluye ORM, autenticación y panel administrativo, permite crear APIs usando Django REST Framework y es recomendado para aplicaciones robustas y seguras.
  • 3️⃣ Spring Boot: Framework basado en Java, muy utilizado en entornos empresariales, facilita la creación de microservicios y es ideal para sistemas grandes y corporativos.
  • 4️⃣ Laravel: Framework de PHP con arquitectura MVC, permite crear APIs REST fácilmente y es muy usado en desarrollo web moderno con PHP.
  • 5️⃣ ASP.NET Core: Framework de Microsoft compatible con C#, ofrece alto rendimiento y seguridad, y es usado en aplicaciones empresariales y servicios en la nube.
🎯 Importancia de los Frameworks en SOA
  • Organizar mejor el código.
  • Implementar seguridad (JWT, OAuth).
  • Manejar rutas y controladores.
  • Conectar con bases de datos.
  • Crear APIs REST o GraphQL.
  • Facilitar pruebas y mantenimiento.
📌 Identificar el Proceso de Desarrollo de Programación de Aplicaciones (API)
🔎 ¿Qué es una API?

Una API (Interfaz de Programación de Aplicaciones) es un conjunto de reglas y protocolos que permite a diferentes aplicaciones comunicarse entre sí. Facilita la integración de funcionalidades entre sistemas, permitiendo compartir datos y servicios sin necesidad de conocer su implementación interna.

🛠 Proceso de Desarrollo de una API
1️⃣ Análisis de Requerimientos
  • Definir qué problema resolverá la API.
  • Identificar los usuarios.
  • Determinar qué datos se manejarán.
2️⃣ Diseño de la API
  • Definir endpoints y métodos HTTP.
  • Seleccionar formato de datos (JSON, XML).
  • Diseñar estructura de respuestas.
3️⃣ Desarrollo
  • Configuración del entorno.
  • Instalación del framework.
  • Creación de rutas y controladores.
  • Conexión a base de datos.
  • Implementación de validaciones.
4️⃣ Pruebas
Se realizan pruebas para verificar:
  • Que los endpoints funcionen correctamente.
  • Que los datos se guarden.
  • Que los errores estén controlados.
Herramientas comunes:
  • Postman
  • Insomnia
  • Jest (para pruebas unitarias)
5️⃣ Seguridad
Se implementa:
  • Autenticación (JWT)
  • Autorización
  • Validación de datos
  • Protección contra ataques (CORS, SQL Injection)
6️⃣ Documentación

Es fundamental documentar la API para que otros desarrolladores puedan entender cómo usarla. Se pueden usar herramientas como Swagger o Apiary para generar documentación interactiva.

Herramientas comunes:
  • Swagger
  • Apiary
  • Postman
  • Redoc
